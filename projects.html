Published Cryptography Utility

@damisile_ayoola/envvault

v1.1.0

"Zero-dependency AES-256-GCM encrypted secret manager with sub-process memory injection." Encrypts plaintext environment secrets into authenticated `.env.vault` files using Node native `crypto` (AES-256-GCM + PBKDF2 SHA-512 key derivation with 100,000 iterations). Injects secrets directly into `process.env` in memory (`envvault run -- npm start`) without writing plaintext passwords to disk.

$ npx @damisile_ayoola/envvault
Technical Specifications:
  • • Cipher Architecture: Authenticated AES-256-GCM encryption with 128-bit authentication tag and Galois Counter Mode integrity verification.
  • • Key Derivation: PBKDF2 SHA-512 key stretching with 100,000 iterations and unique random salts.
  • • Sub-Process Memory Injection: `envvault run` feeds secrets directly into `process.env` without saving unencrypted files to disk.
  • • Git Security Linter: Installs automated pre-commit git hooks (`envvault audit`) to block accidental plaintext secret leaks.

Production Biometric AI Platform (FUTA SLIT)

checkIn — Biometric & Geofenced Attendance System

Live App →

Production university attendance platform engineered for FUTA (Federal University of Technology Akure) School of Logistics and Innovation Technology (SLIT). Solves physical scanner dependency by validating student presence directly on their mobile phones via 3D facial biometrics and GPS geofencing.

Technical Specifications:
  • • Computer Vision: Google MediaPipe FaceMesh extracting 468 3D facial landmarks with 3-tier similarity thresholding (>50% present, 40-50% pending review, <40% fraud reject).
  • • GPS Geofencing: Haversine distance algorithm enforcing a 50-meter radius threshold around active lecturer sessions.
  • • Offline Resilience Engine: Custom IndexedDB payload queueing (`idb`) with automatic background sync when cellular or Wi-Fi connectivity drops.
  • • Hierarchy & Roles: Admin, HOD, Lecturer, Student across 7 SLIT departments (FINT, BIT, EMT, LTT, PMT, PRMT, SIMT).
