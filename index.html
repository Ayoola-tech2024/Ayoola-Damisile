fixmcp

v0.1.0 • npm package

Automated CLI diagnostic tool that scans, validates, and fixes Model Context Protocol (MCP) server configurations across Claude Code, Cursor, and Windsurf environments. Features real-time JSON-RPC 2.0 schema validation and step-by-step configuration repair.

@damisile_ayoola/envvault

v1.1.0 • npm package

Zero-dependency cryptographic CLI tool that encrypts sensitive environment secrets into authenticated .env.vault files using AES-256-GCM cipher and PBKDF2 SHA-512 key derivation. Features automatic git pre-commit hook secret leak blocking.
